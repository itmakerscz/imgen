# nevimto.cz | Local AI Agent Orchestrator 🤖

**nevimto.cz** is a high-performance, privacy-first platform designed to run Large Language Models (LLMs) directly in your browser. Using **WebGPU** and **WebAssembly**, it transforms your browser into a fully local AI workstation.

---

## 🌟 Key Features
- **100% Local Intelligence**: Powered by `WebLLM`. No API keys, no cloud, no subscriptions.
- **Agent Dashboard**: Manage multiple persistent AI Agents.
- **RAG Capability**: Add custom English knowledge bases to each agent.
- **Persistent Memory**: Uses **IndexedDB** to save all agents and chat histories.
- **PWA Ready**: Installable as a Progressive Web App.

## 🚀 Getting Started
1. **Clone the repository**: `git clone https://github.com/itmakerscz/imgen.git`
2. **Local Assets**: Ensure `vue.global.js`, `dexie.mjs`, and `style.css` are in `/assets`.
3. **Run Server**: Serve via `http://localhost:8000` (e.g., VS Code Live Server).
